# Rank XI (concept app)

Every US soccer club — MLS to the grassroots — on one map with one national ranking.

Working concept: 185 real clubs/locations from the project dataset; ratings, records and fixtures are illustrative demo data.

Static site, no build step. Open index.html via any web server.

Deploys: GitHub Pages from main. To add Cloudflare Pages: connect this repo in the Cloudflare dashboard (build command: none, output dir: /).
